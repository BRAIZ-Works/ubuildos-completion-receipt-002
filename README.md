# Follow-Up Prioritizer™ v1.0.0

A narrow Day-1 proof product that turns multiple follow-up items into a deterministic ordered queue with visible ranking reasons.

## What it proves
- multiple competing follow-ups can be ranked consistently;
- every rank exposes the reasons and points behind it;
- the demo uses synthetic/sample data only;
- identical input produces identical output.

Open `app/index.html` in a modern browser. No network connection, account, API, database, or installation is required.
